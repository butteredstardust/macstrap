# VS Code extensions, one id per line. Blank lines and # comments ignored.
#
# Install:  scripts/editors.sh
# Refresh:  code --list-extensions > dotfiles/vscode/extensions.txt
#
# Declare one extension per job. Two extensions doing the same job collide.
# Two Docker extensions give two container views and two sets of palette
# commands. Inline AI suggestions are the worst case: several providers race for
# the same ghost-text slot, and whichever wins is the one you see.
#
# Every extension here earns its startup cost.
