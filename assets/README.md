# assets

Project artwork. Nothing here is read by `bootstrap.sh` or any script — these files exist so the
README has a logo and so the icon can be redrawn without going back to the design tool.

| File                     | What it is                                                                     |
| ------------------------ | ------------------------------------------------------------------------------ |
| `macstrap.png`           | 1024×1024 composed icon. This is the one the README embeds.                    |
| `macstrap.svg`           | Vector source of the same composed icon, rounded backplate included.           |
| `macstrap-freeform.svg`  | The ladder alone, no backplate — for anywhere a square tile would be wrong.    |

The mark is a three-tier isometric ladder: a machine provisioned in layers, which is what the
tiered Brewfiles and the numbered `docs/` describe.
